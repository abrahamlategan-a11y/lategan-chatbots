Pirate host setup

1. Update the Worker

Open lategan-chatbot → Edit code in Cloudflare. Copy all of the current worker.js into this box.

Paste the updated code into the Cloudflare editor and select Deploy.

2. Set your colleague’s host code

Generate a code. In the Worker’s Settings → Variables and Secrets, add a Secret named PIRATE_HOST_CODE. Paste your generated code as the value and deploy.

Privately share the code and the Pirate host page with your colleague. Students use the six-digit join code from the game lobby.
