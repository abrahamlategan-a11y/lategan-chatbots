LATEGAN CHATBOTS

Upload the CONTENTS of this folder to a GitHub Pages repository.

Structure:
index.html                 = main student hub
travel-coach/index.html    = Travel Coach

Suggested GitHub repo name:
lategan-chatbots

Once GitHub Pages is enabled, students can use:
https://YOUR-GITHUB-USERNAME.github.io/lategan-chatbots/

Travel Coach direct link:
https://YOUR-GITHUB-USERNAME.github.io/lategan-chatbots/travel-coach/

To add another bot later:
1. Create a new folder, e.g. science-coach
2. Put that bot's index.html inside it
3. Add a live card on the home page linking to ./science-coach/
